# Vijays-chatbot
# 🤖 Multi-AI Chatbot

A fast, lightweight, and versatile chatbot interface powered by three distinct AI backends: **Google Gemini**, **Groq**, and **OpenReader**. Switch seamlessly between models depending on your needs—whether you want deep reasoning, ultra-fast responses, or web-reading capabilities.

---

## ✨ Features

* **Multi-Provider Support:**
  * 🧠 **Google Gemini:** Advanced reasoning, context processing, and multimodal tasks.
  * ⚡ **Groq:** Ultra-low latency responses powered by LPU acceleration.
  * 📖 **OpenReader:** Specialized processing for web scraping, documents, and reading tasks.
* **Model Switching:** Toggle between backends with a simple config or dropdown UI.
* **Easy Setup:** Simple environment setup for API keys and configuration.
